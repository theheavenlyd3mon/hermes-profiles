# Tech Promo Neon UI Atoms

科技宣传片 / 产品介绍片原子动效资产包。

这套资产沉淀自一个“极简黑场 + 霓虹渐变 + UI 光标交互”的科技宣传片参考风格，用来帮助剪辑师、设计师和视频 agent 快速搭建高端科技感产品片。它不是一条完整视频，而是一组可插拔的原子能力：每个能力都可以单独用在片头、功能点、转场、产品 UI 展示或品牌收尾中。

## 适用场景

- AI 产品、SaaS、数据平台、智能硬件、开发者工具、创意工具宣传片。
- 需要“高级、克制、未来感、产品感”的短视频或横版品牌片。
- 需要在 HyperFrames / HTML / CSS / GSAP 中复用的动效原型。
- 需要先让用户逐项评价，再根据反馈迭代的动效评审流程。

## 总体风格规则

- 以近黑背景承载少量发光元素，避免把画面堆满赛博网格、粒子和大段字幕。
- 主色建议使用蓝、紫、粉、青、少量荧光绿，所有颜色都应服务于“光边”和“焦点”。
- 文案只用 1-3 个词，表达抽象价值，例如 `Focused`、`Smart Focus`、`Giving Space`。
- 鼠标、选择框、圆角胶囊、数据路径、节点网络、Logo 收束都可以作为“产品正在被操作”的暗示。
- 动效以光线描边、形变展开、光标引导、扫描锁定、Zoom in / Zoom out、短暂闪光为主。

## 原子动效清单

### 01. 光线描边圆角 `neon-line`

定位：推荐保留。

用途：作为 0.5-1.5 秒的“界面出生”镜头，把光线改成产品卡片轮廓、数据路径、Logo 外框或章节分隔线；也可以接在黑场后，用一条光边先勾住观众注意力。

实现要点：SVG path draw，使用 `stroke-dasharray` / `stroke-dashoffset` 做描边，搭配霓虹渐变和柔和 bloom。

### 02. 光标激活胶囊 `cursor-pill`

定位：可用，但必须保证光标命中目标。

用途：展示“专注 / 智能 / 自动化 / 一键生成”等抽象价值词。适合产品功能点之间的 1 秒小节奏。

实现要点：胶囊先横向展开，光标移动到右侧小圆按钮后触发 spark 与轻微按压。箭头终点必须真实落在按钮上，不能只“擦边”。

### 03. 聚焦扫描镜头 `focus-scan`

定位：眼睛图形不保留，改为更抽象的扫描聚焦。

用途：AI 检索、智能聚焦、扫描识别、从复杂信息里锁定重点。相比眼睛图形，扫描环 + 目标框 + 光束更干净、更产品化。

实现要点：圆形扫描环旋转，中心目标由圆形过渡到圆角方块，横向扫描线穿过目标，最后出现短词 `Smart Focus`。

### 04. 环形点阵聚合 `orbit-dots`

定位：单独使用略普通，需要增强。

用途：生态、网络、数据中枢、协同系统。不要只放一圈点，需加入节点连线、数据流、信号点或三维倾斜感。

实现要点：环形节点带透视倾斜，中心核心 pulsing，节点到中心有虚线连接，一枚信号光点绕环运动。

### 05. 选择框扩展留白 `selection-space`

定位：强推荐保留。

用途：产品编辑器、设计工具、空间释放、可视化操作。这个方向的关键是 Zoom in / Zoom out 的镜头手感，适合沉淀为产品 UI 类默认模板。

实现要点：选择框从细线扩展成区域，四角控制点出现，光标轻微推动画面，整体有推近/拉远的空间感。

### 06. 品牌收束 `brand-lockup`

定位：推荐保留。

用途：片尾 Logo、品牌主张、官网/产品名露出。

实现要点：一条微光线先出现，然后聚成 Logo / symbol，再出现产品名。真实项目中应替换占位 Logo，并设计 2-3 种不同强度的收尾节奏。

## 推荐剪辑结构

这套原子能力可以拼成一条 20-40 秒科技产品片：

1. 0-3 秒：用 `neon-line` 做黑场开场，勾勒产品轮廓或数据路径。
2. 3-8 秒：用 `cursor-pill` 激活第一个价值词，例如“Focused”。
3. 8-14 秒：用 `focus-scan` 展示 AI / 智能识别 / 自动聚焦能力。
4. 14-20 秒：用 `orbit-dots` 展示数据网络、生态或协同关系。
5. 20-30 秒：用 `selection-space` 做核心产品 UI 镜头，重点强化 Zoom in / Zoom out。
6. 30-36 秒：用 `brand-lockup` 收束到 Logo、官网和品牌主张。

## 评审与迭代流程

1. 先打开 `preview.html` 或把原子卡片嵌入评审台。
2. 对每个原子动效单独填写反馈，而不是只评价整条视频。
3. 反馈按 `atoms.json` 的 `id` 对齐，例如 `selection-space`、`brand-lockup`。
4. 修改时优先保留已标为 `recommended` 的能力，对 `needs_iteration` 的能力只增强，不直接弃用。

## 文件说明

- `README.md`：给人看的使用说明和风格规则。
- `atoms.json`：给 agent / 程序读取的结构化模板配方。
- `preview.html`：轻量可视化预览页，直接用浏览器或静态服务打开即可。

## 设计禁忌

- 不要把所有原子能力串成一条不可拆的视频再让用户评价。
- 不要用眼睛图形作为默认 AI 聚焦隐喻，容易显得像 Logo 或不够高级。
- 不要让光标只是移动到附近，交互型特效必须看起来真实命中目标。
- 不要让环形点阵只有一圈点，必须增加网络关系、数据流或纵深。
- 不要在黑场里塞满复杂字幕，短词和少量 UI 元素更高级。
