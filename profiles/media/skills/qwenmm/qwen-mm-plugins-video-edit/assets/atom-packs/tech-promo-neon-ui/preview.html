Tech Promo Neon UI Atoms

科技宣传片 / 产品介绍片原子动效资产。每张卡都是一个可独立复用的能力，不是完整成片。优先复用选择框 Zoom in / Zoom out、品牌收束、光线描边三类效果。

Atom 01

光线描边圆角

recommended
用于片头、产品轮廓、数据路径、Logo 外框。把 SVG path 替换成目标形状即可复用。
Atom 02

光标激活胶囊

hit target
用于价值词激活和功能点出现。光标必须真实命中右侧小按钮。
Atom 03

聚焦扫描镜头

reworked
Smart Focus
替代眼睛图形，用扫描环、目标框和扫描线表现 AI 聚焦。
Atom 04

环形点阵聚合

enrich
用于生态、网络、数据中枢。必须叠加连线、信号流或纵深，避免像普通加载动画。
Atom 05

选择框扩展留白

strong
强推荐。用于产品编辑器和核心 UI 镜头，重点保留 Zoom in / Zoom out 空间手感。
Atom 06

品牌收束

ending
NEON UI KIT
用于片尾 Logo、品牌主张、官网露出。正式项目替换真实 Logo 并保留最终 hold 帧。
