# Build-Order Discipline — Pre-Draft Sequence

Non-negotiable ordering before any chapter is drafted. Established 2026-07-21 after user correction: "lets break down what needs to be done into steps. rather than jump all over the place."

## The Sequence

### Phase 1 — Characters (before any prose)

Build ALL named character sheets using the `character-builder` skill template. Order by story appearance:

1. Protagonist + immediate family (review/tighten existing)
2. Companions (full personality, voice, dialogue profiles)
3. Antagonists (motivation, method, relationship to protag)
4. Authority figures (name, judgment style, institutional role)
5. Background characters (function + impression only — keep minimal)

**Per-character workflow:**
1. Fill template (core + role tags)
2. Interiority test (contradiction, physical anchor, surprise test)
3. Dialogue distinctiveness test (3-4 sample lines, remove tags, verify identifiable)
4. Gap check (interaction matrix — who hasn't met whom?)
5. Lock → write into vault, update canon

**Why first:** You cannot write distinct dialogue for four companions if you don't know who they are. Personality drives voice drives prose. Build the people before they speak.

### Phase 2 — World (fill gaps the story will touch)

Only what THIS book needs. Iceberg the rest.

1. Primary locations (home, first city, dungeons)
2. Systems the plot depends on (guild, magic, star-ratings)
3. Species norms (how do the companion species coexist?)
4. Factions (stubs with known facts + open questions)

**Why second:** Characters walk through a world. You need to know what the guild hall looks like before writing the registration scene, but you don't need the full political history of the Ascendants for Book 1.

### Phase 3 — Voice Calibration

1. Review voice-profile.md (register, banned words, rhythm targets)
2. Write a short sample (200-300 words, ch01 opening)
3. Review against anti-slop + stability trap
4. Lock the profile

**Why third:** Voice depends on knowing WHO is speaking (Phase 1) and WHERE they are (Phase 2). Calibrating voice for a character you haven't built yet produces generic prose.

### Phase 4 — Draft, Chapter by Chapter

Linear order. No exceptions for linear stories.

- Plants in ch03 pay off in ch04 — you need ch03 written to know what you planted
- Voice locks in ch01 — later chapters reference the established register
- Character arcs build sequentially — you can't write the Dark Night before the Midpoint

Each chapter: draft → review (fresh context) → revise → gate check → next chapter.

## Anti-Patterns

- ❌ "Let's just start writing ch01 and figure out the companions later"
- ❌ Building world lore for Book 3 when Book 1 hasn't been drafted
- ❌ Writing ch04 (ambush) before ch03 (rest-talk plant) because the action is more exciting
- ❌ Calibrating voice with a generic sample instead of the actual opening scene
- ❌ Building all 5 books' worth of characters before drafting Book 1

## When to Deviate

- Non-linear narratives (flashbacks, parallel timelines) may require drafting the "present" thread first, then filling backstory
- If the user explicitly says "I want to write this scene now" — respect it, but flag what's missing
- Voice samples can double as ch01 drafting (two birds, one stone) if the opening is clear
