# Visual Profile Workflow & AI-Tell Patterns

## Detailed Process

### 1. Gather source material
- Read all relevant character sheets (protagonist + companions)
- Read species docs for any established visual canon
- Note physical tics from dialogue sections (these inform posture/manner)
- Note symbolic objects — they should appear visually

### 2. Build each character
Work through: Face → Eyes → Hair → Build → Clothing → Weapons/Magic → Posture → Palette

For each field:
- Be specific: "burnt sienna with rust flecks" not just "orange"
- Include measurements where relevant (height, proportions)
- Describe how things move/behave (hair in wind, wings when emotional)
- Note what's visible vs hidden (cloak usually pushed back, etc.)

### 3. Palette table
```markdown
**Palette:**
| Element | Color | Hex |
|---------|-------|-----|
| Hair | Overcast grey-white | #C8C8CC |
| Eyes | Dying ember orange | #D4723C |
| Skin | Pale, cool undertone | #E8DDD4 |
```

Include: hair, eyes, skin, primary clothing, secondary clothing, weapons/gear, living/organic parts.

### 4. Humanizer pass (mandatory)

Visual descriptions accumulate specific AI tells. Run through this checklist:

#### Negative parallelism (pattern 9)
**Bad:** "not sickly, just rarely in direct sun"  
**Good:** "rarely in direct sun"

**Bad:** "Not fragile — the kind of thin that comes from forgetting to eat"  
**Good:** "Thin in the way of someone who forgets meals"

**Bad:** "boots made for climbing, not marching"  
**Good:** "boots made for climbing"

**Fix:** When you see "not X, [but/just] Y", ask if the positive statement alone is clearer.

#### Rule-of-three punchy pairs (pattern 31)
**Bad:** "Nothing decorative. Nothing that draws attention."  
**Good:** "Deliberately unremarkable."

**Bad:** "Nothing matches. Everything works."  
**Good:** "His gear doesn't match but it all works."

**Bad:** "Everything dark. On purpose."  
**Good:** "She wears dark colors intentionally."

**Fix:** Compressed punchy pairs read as AI. Merge into single statements.

#### Forced metaphors (pattern 30)
**Bad:** "like spider silk made of smoke"  
**Good:** "thin and smoky"

**Bad:** "like a bruise that's almost healed"  
**Good:** (delete, just describe the color)

**Bad:** "like two drops of ink"  
**Good:** (delete, describe what they actually look like)

**Fix:** Visual descriptions don't need poetic metaphors. State color/shape/texture directly.

#### "The kind of" constructions
**Bad:** "the kind of thin that hides functional strength"  
**Good:** "thin in a way that hides functional strength"

**Bad:** "the kind of eyes that make you trust someone"  
**Good:** "trustworthy eyes"

**Bad:** "the kind of thin that comes from forgetting to eat"  
**Good:** "thin in the way of someone who forgets meals"

**Fix:** "The kind of X that Y" is verbose. Rephrase with direct description.

#### Dramatic fragmentation (pattern 31)
**Bad:** "Appears fourteen years old. Ninety-eight."  
**Good:** "Appears fourteen years old. Is ninety-eight."

**Bad:** "She'd never let anyone get close enough."  
**Good:** "She keeps people at a distance."

**Fix:** Mic-drop fragments read as performative. State the fact plainly.

### 5. Final check
- [ ] All character sheets consulted
- [ ] Species canon respected
- [ ] Physical tics included in posture/manner
- [ ] Hex codes for all elements
- [ ] Humanizer pass complete (all 5 pattern types checked)
- [ ] No negative definitions
- [ ] Direct, specific descriptions throughout
