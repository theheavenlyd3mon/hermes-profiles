# Prosody: The Master Framework for Songwriting

**Source:** Pat Pattison (Berklee Online), Aristotle's *Poetics*
**Loaded by:** `songwriting-and-ai-music` skill

---

## Definition

> Prosody is when ALL elements work together to support the central message of the song.

Every element — rhyme type, chord voicing, vocal delivery, arrangement density, melodic contour — either supports the emotional intent or fights it. The framework for choosing is **Stable vs Unstable**.

---

## The Stable vs Unstable Framework

Ask first: *What idea am I dealing with? Is it stable or unstable?* Then build every element to support that classification.

| Element | Stable (Resolved, Peaceful, Certain) | Unstable (Longing, Doubt, Tension) |
|---------|--------------------------------------|-------------------------------------|
| **Rhyme** | Perfect rhyme (fire/desire) | Assonance rhyme (life/tide) |
| **Family Rhyme** | Family rhyme (mud/truck) | Consonance rhyme (scene/when) |
| **Melody** | Conjunct (stepwise), settled, small range | Disjunct (leaps), wide, wandering |
| **Harmony** | Diatonic, resolved cadences (V→I) | Extended chords, suspended, dim7 |
| **Rhythm** | Steady, on-beat, consistent | Syncopated, off-grid, swung |
| **Vocal** | Full, chest voice, steady | Breathy, head voice, strained |
| **Arrangement** | Full, warm, saturated | Sparse, empty, dissonant, abrupt cuts |
| **Meter** | Regular, matched syllables | Irregular, intentionally broken |

---

## Prosody and Rhyme Types

| Rhyme Type | Definition | Prosody Effect |
|------------|------------|----------------|
| **Perfect** | Same vowel + same ending consonants (fire/desire) | **Stable** — finality, certainty |
| **Family** | Same vowel + phonetically related consonants (mud/truck) | **Stable** — soft, less final |
| **Additive/Subtractive** | Same vowels ± a consonant (eve/believe) | Near-stable |
| **Assonance** | Same vowel, different consonants (life/tide) | **Unstable** — ambiguous |
| **Consonance** | Different vowels, similar consonants (scene/when) | **Unstable** — edgy, unsettled |

### Demonstration: Same Idea, Different Prosody

**Perfect rhyme — resolved, final:**
> *You think that I'll get over it?*  
> *Just stand right there and watch me **split**.*

→ Sounds like it's really over. Finality.

**Assonance rhyme — ambiguous, unresolved:**
> *You think it's something I don't mean?*  
> *Just stand right there and watch me **leave**.*

→ Not quite resolved. Perfect for situations where they don't really want to leave.

## Applying to RIVEN vs SOLA

### RIVEN = Unstable Territory
- **Rhymes:** Assonance, consonance, slant rhymes for ambiguity
- **Harmony:** Minor keys, extended minor chords, dim7, unresolved cadences
- **Vocal:** Breathy verse → belted chorus = emotional whiplash
- **Arrangement:** Sparse, dark, sudden cuts, chaotic breakdowns
- **Rhythm:** Syncopated, swung, off-grid trap pockets
- **Lyrics:** Doubts, regrets, the spaces between words

### SOLA = Stable Territory
- **Rhymes:** Perfect and family rhymes for warmth and closure
- **Harmony:** Maj7 and 9th chords, resolved progressions
- **Vocal:** Smooth build, sustained notes, runs
- **Arrangement:** Full, warm, layered, blooming
- **Rhythm:** On-pocket, groove-based, steady
- **Lyrics:** Recognition, arrival, certainty, warmth

---

## How to Check Prosody

1. Identify the emotional intent of each section (stable or unstable?)
2. Check each element against the table above
3. Ask: *Does this support the emotional intent or fight it?*
4. If it fights, either change the element or change the intent

**Exception:** Intentionally mixing stable/unstable creates complexity:
- Stable memory + unstable present = **nostalgia**
- Stable beauty + unstable loss = **bittersweet**
- Stable declaration + unstable delivery = **vulnerability**
