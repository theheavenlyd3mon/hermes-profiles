# TrapSoul Vibe A — Male Vocal Template for Suno

## When to Use

A user gives a **theme + direction** and wants everything needed for Suno:
a complete DSL style prompt + full lyrics, in a cohesive Trap Soul / male R&B / glitchy lo-fi style.

This skill IS the methodology extracted from a dissected reference track. It captures
the production palette, rhyme schemes, structural patterns, and lyrical approach — so any
theme can generate a track in this style.

---

## Quick Reference — The Pipeline

```
INPUT: Theme (one sentence) + Direction (mood, energy, emotional arc)
  ↓
1. Build Extended Metaphor System (locked to theme)
2. Select Structure Variant (A/B/C)
3. Choose DSL Energy Arc (arc 1/2/3)
4. Apply Rhyme Scheme per section
5. Write Lyrics (using methodology rules)
6. Assemble DSL Style Prompt
7. OUTPUT: Copy-paste ready Style + Lyrics
```

## Step 1 — Build the Extended Metaphor System

The entire song lives inside ONE metaphor. Every line extends it. No mixed metaphors.

**Method:** Map your theme onto a concrete symbolic system.

| Theme Feel | Metaphor Systems to Consider |
|---|---|
| Defiance against invisible force | Warrior vs. Shadow, Soldier vs. Signal, Captain vs. Storm |
| Loss / grief | Extinguished light, abandoned architecture, frozen seasons |
| Obsession / chasing | Hunter and hunted, diver and deep, architect and ruin |
| Identity fragmentation | Mirror worlds, doppelgänger, mask and face |
| Late-night solitude | Empty city, lighthouse keeper, last broadcast |
| Forbidden love | Alchemist and poison, sacred trespass, fire and glacier |

**Rules:**
1. Pick TWO entities in tension (protagonist + force)
2. Give each entity 3-4 attributes you can reference later
3. The force should be ABSTRACT made CONCRETE (algorithm → ninja, grief → rising water)
4. The protagonist should be ROOTED and HUMAN (samurai, lighthouse keeper, driver)

**Example from reference:**
```
Protagonist: Samurai (honor, blade, courtyard, bare chest, open road)
Force: AI as Ninja (shadow, code, silent, throat-cut, algorithm)
```

## Step 2 — Select Structure Variant

Three structural templates. Match to emotional intent.

### Variant A — "Build to Break" (Anthem)
Best for: Defiant, declarative, building intensity.  ~3:30

```
Intro (8 bars)      → atmospheric, motif only, reversed textures
Verse 1 (8 bars)    → sparse drums, intimate, world-building
Pre-Chorus (4 bars) → tension lift, half-time shift, stabs enter
Hook (8 bars)       → full 808 drop, dense, anthem
Verse 2 (8 bars)    → same melody, escalated density
Pre-Chorus (4 bars)
Hook (8 bars)       → glitch variations, layered vocals
Breakdown/Bridge (4 bars) → stripped, modular synth, spoken energy
Final Hook (8 bars) → double-time layers, ad-libs, max density
Outro (4 bars)      → motif returns, reverb tail, fade
```

### Variant B — "Slow Burn" (Introspective)
Best for: Melancholic, drifting, vulnerability-forward. ~3:00

```
Intro (8 bars)
Verse 1 (12 bars)   → extended, conversational, no rush
Hook (8 bars)       → not a drop — a bloom (warm saturation, not loud)
Verse 2 (12 bars)
Hook (8 bars)
Bridge (8 bars)     → the emotional peak, not a quiet one
Outro (8 bars)      → long decay, elements drift apart
```

### Variant C — "Glitch Descent" (Experimental)
Best for: Chaotic, fragmented, psychological. ~2:48

```
Intro (4 bars)      → abrupt, mid-phrase feel, tape start
Verse 1 (8 bars)    → stutter drums, not yet pocketed
Hook (8 bars)       → 808 hit, then glitch cut to half
Verse 2 (8 bars)    → more fragmented than V1
Hook Variant (4 bars) → corrupted, bit-crushed
Bridge (8 bars)     → total deconstruction, modular noise
Outro (8 bars)      → no resolution, tape stop mid-word
```

## Step 4 — Rhyme Scheme Per Section

### Verses — Paired Couplets with Internal Anchors
```
A (end rhyme, line 1)
A' (internal anchor sets up: assonance/slant on line 2 midpoint)
B (end rhyme, line 2 — perfect or family)
  — rest bar or beat —
C (end rhyme, line 3)
C' (internal anchor on line 4 midpoint)
D (end rhyme, line 4)
```

**Internal Anchor Technique:** Mid-line word rhymes with the approaching end rhyme.
```
"My BRUSH is a ka-TA-na" (TA-na anchors to...)
"my INK is the BLOOD of the HEART" (heart sets up...)
"carve the GLO-ry in every rhythmic PART" (heart/part = perfect landing)
```

### Hook — Stacked Alternating (Anthem Stack)
```
E / E'  (same rhyme, back to back — incantation feel)
F / F'  (new rhyme, back to back)
G / G'  (escalation rhyme)
H / H'  (final declaration)
```

This creates a "wall building" effect — each pair adds weight.
All 8 lines of the hook can share just 4 rhyme sounds.
Use PERFECT or FAMILY rhymes here — the hook needs to lock.

### Bridge — Break the Pattern
Switch to ABAB or go monorhyme (AAAA) for hypnotic intensity.
This is the philosophical turn — a question, a revelation, a direct address.

### Outro — Fragment / Non-Rhyme
2-3 short lines. No need to rhyme. Function as haiku-resolution.

## Step 5 — Lyric Writing Methodology

### Rule 1: Extended Metaphor As Architecture
Every verse line must reference the metaphor system. No decorative lines.
If your system is "Lighthouse Keeper vs. the Fog" — every image is light, glass, rotation, storms, ships, cliffs, erosion.

### Rule 2: Sensory Contrast Juxtaposition
Pair an ORGAIC/natural image with a TECH/industrial descriptor:
- "digital sliver" (tech + nature)
- "crimson song of honor" (color + sound + value)
- "bars are made of code" (prison + digital)
- "ghost-filled, empty road" (spectral + physical space)

### Rule 3: Philosophical Turn at Midpoint
Before or inside the bridge, step outside the narrative and ASK A QUESTION or state a thesis. This is the "why does this matter" moment.

Patterns:
- "Is this the new universe? Where [consequence]?"
- "If [action] and no one hears, does [thing] still [exist/matter]?"
- "We traded [soul thing] for [hollow thing], but [forgot/lost]..."

### Rule 4: Refrain as Incantation
The hook repeats with near-identical structure. It's a MANTRA, not a story progression.
Vary only 1-2 words between repetitions for evolution.

```
First time:  "I am the Noble Blade, writing for the heavens to see"
Second time: "I am the Noble Blade, writing what the darkness needs to see"
```

### Rule 5: Outro as Haiku Resolution
Three short lines that resolve the metaphor system:
- Line 1: The force acts ("The Ninja strikes...")
- Line 2: The protagonist responds ("The Samurai stands...")
- Line 3: The thesis ("The silence is screaming.")

Each line 3-6 syllables. Parenthesized or italic treatment in Suno metatags.

### Rule 6: Syllable Count Guidelines
- Verses: 12-16 syllables per line (comfortable sung-rap flow)
- Hook: 10-14 syllables per line (tighter, more rhythmic)
- Bridge: 14-18 syllables (more words, more philosophical)
- Outro: 3-6 syllables per line

## Tips

- **Motifs are anchors:** The chopped bell motif appears in intro, transitions, and outro. Always name your motif in the style tag.
- **Tape saturation = warmth:** Use this word when you want Suno to avoid digital harshness.
- **Reversed vinyl in intro, normal in outro:** Bookending with time manipulation creates a "dream logic" feel.
- **Don't over-tag Suno:** 5-8 tags per section max. The DSL arc handles the macro dynamics.
- **Phonetic respelling for tricky words:** Spell words as they SOUNCE if AI mispronounces them.
- **Test the bell motif early:** Generate a 30-second clip of just intro+hook before committing to full length.
- **Variable generation:** Always request 3-5 variations — the groove pocket varies significantly between generations.
