# DSL Energy Arc Patterns

## Building the Middle Section of a DSL Style Prompt

The DSL style prompt has three parts. This template covers **Part 2** — the
layer-by-layer energy arc (L0-L5). Each line plugs directly into the DSL block.

### Structure

```
$S(x)$ lifecycle [overall energy function],
[Part 2 — each Lx line below],

[Final genre tag]
```

### Full RIVEN DSL Block (Default)

```
$S(x)$ lifecycle $dE/dx>0 \to b=1 \to 0$,
$E(x)$ monotone $dE/dx>0$ L0-L2
then $b(x):0\to1$ at $x=\gamma$ $E_{max}$
then $dE/dx<0$ to $\lim E=0$,

L0-L1 EXTENDED slow $\nearrow$ ambient $b=0$ sustained sparse piano atmosphere,
L2 $30eE$ swell tension building hi-hats enter,
L3 sudden $b=1$ $E_{max}$ catastrophic 808 sub-bass drop,
L4 $\phi'_j\sim\mathcal{N}(0, \sigma^2)$ $\infty$ $dE/dx<0$ chaotic breakdown noise,
L5 instant snap $\lim_{x\to1}E=0$ $\oslash$ silence,

Trap soul dark noir
```

### Full SOLA DSL Block (Default)

```
$S(x)$ lifecycle $dE/dx>0$ gradual $b=0$ sustained,
then $dE/dx<0$ to $\lim E=0$,
$E(x)$ slow rise to $E=6$ held then $dE/dx<0$,

L0 voice keys $b=0$ intimate breathy solo,
L1 $dE/dx>0$ warm bass pad enters,
L2 $E=6$ sustained chorus bloom full warmth,
L3 bridge $dE/dx>0$ to $E=8$ emotional belt peak,
L4 $\lim E\to0$ float to silence breath fade,

R&B alt-pop ethereal
```

---

## Layer Line Components

Each layer line = **Layer label + DSL notation + texture words**

| Layer | DSL to Use | Texture Space |
|-------|------------|---------------|
| **L0** | $b=0$, slow, ambient | Atmospheric opener |
| **L0-L1** | $b=0$ sustained, $\nearrow$ | Extended ambient build |
| **L1** | $dE/dx>0$, gradual | First verse, entering |
| **L2** | $30eE$, $\nearrow$, $dE/dx>0$ | Pre-chorus tension, swell |
| **L3** | $b=1$, $E_{max}$, sudden | Chorus, drop, saturation |
| **L4** | $\phi'_j$, $\infty$, $dE/dx<0$ | Bridge, breakdown, decay |
| **L5** | $\lim E\to0$, $\oslash$, snap | Outro, silence, cut |

## Complete DSL Arc Library (12 Patterns)

### #1 — Classic Build-Drop (RIVEN default)
Build tension slowly, drop hard into chaos, cut to silence.

```
L0-L1 EXTENDED slow $\nearrow$ ambient $b=0$ sustained {texture},
L2 $30eE$ swell {texture},
L3 sudden $b=1$ $E_{max}$ catastrophic {texture},
L4 $\phi'_j\sim\mathcal{N}(0, \sigma^2)$ $\infty$ $dE/dx<0$ chaotic {texture},
L5 instant snap $\lim_{x\to1}E=0$ $\oslash$ silence,
```

### #2 — Slow Float (SOLA default)
Gentle rise to warmth, hold, then float to silence.

```
L0 voice keys $b=0$ intimate {texture},
L1 $dE/dx>0$ warm {texture},
L2 $E=6$ sustained chorus {texture},
L3 bridge $dE/dx>0$ to $E=8$ {texture},
L4 $\lim E\to0$ float to silence breath fade,
```

### #3 — One-Way Crescendo
Builds continuously, never drops — sustains at peak until the end.

```
L0-L1 slow $\nearrow$ ambient $b=0$ sustained,
L2 $dE/dx>0$ growing,
L3 $b=1$ $E_{max}$ peak,
L4 $b=1$ sustained saturation,
L5 $b=1$ held fade,
```

### #4 — Stutter Dynamics
Sharp alternations between fullness and emptiness. Disorienting.

```
L0 $b=0$ ambient,
L1 $\oslash$ cut,
L2 $b=1$ $E_{max}$ sudden,
L3 $\oslash$ cut,
L4 $b=0$ whisper,
L5 $\oslash$ silence,
```

### #5 — Ambient Explosion
Long sustained ambient section, then sudden explosion and cut.

```
L0-L2 EXTENDED $b=0$ sustained ambient,
L3 $30eE$ into $b=1$ $E_{max}$,
L4 $\phi'_j\sim\mathcal{N}(0, \sigma^2)$ $\infty$,
L5 instant $\oslash$,
```

### #6 — Crescendo Collapse (RIVEN — aggressive)
Build to absolute maximum, then instant cut to silence. The silence is the point.

```
L0-L1 slow $\nearrow$ ambient $b=0$ sustained sparse minimal,
L2 $dE/dx>0$ 808 enters heartbeat,
L3 $30eE$ swell trap rolls tension peaks,
L4 $b=1$ $E_{max}$ full saturation EVERYTHING,
L5 instant $\oslash$ cut to silence,
(optional L6) $b=0$ whisper reprise
```

### #7 — Float with Spike (SOLA — dynamic warmth)
Warm float, then a sudden emotional spike, then rapid decay back to breath.

```
L0 voice keys $b=0$ intimate breath,
L1 $dE/dx>0$ warm pad slow bloom,
L2 $E=6$ sustained chorus full float,
L3 $b=1$ sudden to $E=8$ emotional spike belt,
L4 $\lim E\to0$ rapid decay to breath,
L5 $b=0$ held fade sustained warmth
```

### #8 — Anti-Chorus (both — subvert expectation)
Build toward a drop, then pull the arrangement out from under. The emptiness IS the impact.

```
L0-L1 build $b=0$ to $b=1$ classic tension,
L2 L3 $E_{max}$ saturation full power pre-drop,
L3 L4 $b=0$ sudden drop to voice-keys only,
(the emptiness IS the impact)
L5 $\lim E\to0$ breath fade
```

### #9 — Jagged Push-Pull (RIVEN — emotional whiplash)
Never settles. Cycles between tension and release, each cycle shorter.

```
L0 $b=0$ ambient tension,
L1 $b=1$ sudden burst,
L2 $b=0$ collapse back,
L3 $\nearrow$ quick build,
L4 $b=1$ $E_{max}$ maximum,
L5 $\oslash$ cut
```

### #10 — Slow Burn (SOLA — extended float)
Starts almost silent and builds across the entire song. Peaks at the bridge. Never drops hard.

```
L0-L2 EXTENDED $b=0$ sustained ambient,
L3 $dE/dx>0$ very gradual warmth enters,
L4 $E=6$ held at peak no drop,
L5 $\lim E\to0$ gentle decay
```

### #11 — Stutter-Step Drop (RIVEN — false drops)
Multiple false drops before the real one. Each fake-out increases anticipation.

```
L0 $b=0$ sparse minimal,
L1 $\nearrow$ 30eE build toward drop,
L2 $b=0$ pulled back at last second,
L3 $\nearrow$ 30eE build again faster,
L4 $b=1$ $E_{max}$ REAL drop full saturation,
L5 $\oslash$ silence
```

### #12 — Whisper Cascade (SOLA — layered build)
Each section adds one new element. Grows by accumulation, never by drop.

```
L0 voice keys $b=0$ breath solo,
L1 $dE/dx>0$ pad enters slow,
L2 $E=4$ gentle percussion joins,
L3 $E=6$ bass enters chorus warmth,
L4 $E=7$ full bloom no drop just accumulated fullness,
L5 $\lim E\to0$ gentle reverse — elements leave one by one
```

## Energy Arc Quick Reference

```
b=0 → b=0 → b=1 → b=0 → b=1 → ⊘    #1  classic build-drop-restore
b=0 → b=1 → b=1 → b=1 → ⊘           #3  one-way crescendo
b=0 → ⊘ → b=1 → ⊘                    #4  stutter dynamics
b=0 sustained → 30eE → ∞ → ⊘         #5  ambient explosion
↗ → ↗ → 30eE → E_max → ⊘            #6  crescendo collapse
b=0 → ↗ → E=6 → E=8→0 → b=0         #7  float with spike
b=0→1 → E_max → b=0                  #8  anti-chorus
b=0→1→0→1↗→1→⊘                       #9  jagged push-pull
b=0→b=0→↗→E=6→lim→0                  #10 slow burn
b=0→↗→0→↗→1→⊘                        #11 stutter-step drop
b=0→+1→+2→+3→full→decay              #12 whisper cascade
```

- `b=0 ░` calm/ambient
- `b=1 ▓` full energy
- `↗` slow rise
- `30eE` massive exponential
- `∞` loop
- `⊘` silence
- `E=#` energy level 0–10
- `→0` decay to zero
- `+N` add one layer

| 4 | Stutter Dynamics | RIVEN | Glitchy, unhinged, fractured emotion |
| 5 | Ambient Explosion | RIVEN | Sudden emotional breakthrough |
| 6 | Crescendo Collapse | RIVEN | Most dramatic — catharsis then void |
| 7 | Float with Spike | SOLA | When warmth needs an emotional peak |

| 9 | Jagged Push-Pull | RIVEN | Emotional whiplash, hot-and-cold |
| 10 | Slow Burn | SOLA | Long-form story, patient unfolding |
| 11 | Stutter-Step Drop | RIVEN | Tease and reward, anticipation |
