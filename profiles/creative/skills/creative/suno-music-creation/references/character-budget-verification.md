# Character Budget Verification

## Rule
Do not silently trim or expand lyrics to an assumed limit. Treat stated character counts as hard constraints.

## Suno Reference Limits
- **Style field:** ~1,000 characters
- **Lyrics field:** ~3,000 characters (~40–60 lines)

## Workflow Add
After drafting any Suno deliverable, count the chars and report the total count to the user before final delivery. If trimming, keep structural sections intact: hook, chorus, and bridge lines have highest retention priority.

## Common Pitfall
Assuming 1,000-character budgets and trimming valid expanded verses. Expand when the user asks, trim only to their stated number, and always verify with a tool-side check rather than estimating.
