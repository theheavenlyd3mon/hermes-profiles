# Brand Name Brainstorming Workflow

## Constraint: Start at the Punchline
Think of the vibe first, then reverse-engineer the name.

## Step 1: Define Vibe Categories
Present names across 2-3 aesthetic directions:
- **Evocative / Atmospheric** — ethereal, cinematic, emotional
- **Bold / Tech-Forward** — direct, memorable, technical edge
- **Niche-Aligned** — nods to the specific art style (anime, 3D, pixel, etc.)

## Step 2: Generate 6-10 Names Per Category
Each name should be:
- 1-3 words max
- Easy to pronounce
- Available as handle (check after narrowing)
- Visually brandable (works in a logo, as a hashtag)

## Step 3: Narrow to Top 3
Present with rationale:
- What the name evokes
- How it works across platforms
- Visual brandability
- Uniqueness in the space

## Step 4: Validate
- Search X, Instagram, TikTok for handle availability
- Check domain availability if relevant
- Say it out loud — does it feel right?

## Cultural/Fandom Naming Patterns

When user has a specific fandom or cultural aesthetic (martial arts manhwa, 
anime, etc.), lean into that vocabulary:

### Korean Martial Arts Manhwa Pattern
- **Direct terms:** 천마 (Cheonma/Heavenly Demon), 마왕 (Maewang/Demon King)
- **Concept translations:** "Celestial Fiend", "Heavenly Stroke", "Demon's Brush"
- **Fusion names:** Combine Eastern concept + art term (e.g., "Cheonma Ink")
- **Why it works:** Authentic, memorable, signals niche to fellow fans, 
  visually striking as a handle

### General Pattern
1. Identify the user's fandom/aesthetic universe
2. Extract key terms (names, concepts, locations)
3. Translate or transliterate for broader appeal
4. Fuse with art/creative vocabulary
5. Test: Does it work as a handle? Is it pronounceable? Does it signal the niche?

## Anti-Patterns to Avoid
- Generic AI prefixes ("AI-Art-", "GenAI-")
- Overly literal names ("I Make Art")
- Names that only work in one context
- Hard to spell or pronounce
- Already common in the AI art space
