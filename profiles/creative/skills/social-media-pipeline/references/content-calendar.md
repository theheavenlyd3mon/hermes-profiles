# Content Calendar Template

## Weekly Theme Structure

| Day | Content Type | Platform | Notes |
|-----|--------------|----------|-------|
| Monday | Scene of the Week | X + IG | Hero piece, high effort |
| Tuesday | Process/BTS | X thread | How it was made |
| Wednesday | Community/Engagement | X | Poll, question, RT others |
| Thursday | Quick Generation | IG Story | Test new prompts/styles |
| Friday | Before/After or Comparison | X + IG | Show evolution |
| Saturday | Experimental/Trend | TikTok + X | Try new techniques |
| Sunday | Rest or Batch Prep | — | Generate next week's content |

## Content Pillar Definitions

### Pillar 1: Hero Pieces
- **What:** Polished, high-quality scenes or character art
- **Frequency:** 2-3 per week
- **Platform:** X (main), Instagram (grid)
- **Format:** Single image, high resolution
- **Caption:** Short, evocative. Let the art speak.

### Pillar 2: Process Content
- **What:** Behind-the-scenes, workflow breakdowns, prompt sharing
- **Frequency:** 1-2 per week
- **Platform:** X (threads), Instagram (carousels)
- **Format:** Multi-image thread or carousel
- **Caption:** Educational, share knowledge

### Pillar 3: Community
- **What:** Engagement posts, features, collaborations
- **Frequency:** 1-2 per week
- **Platform:** X (primary)
- **Format:** Text, polls, retweets with commentary
- **Caption:** Conversational, build relationships

### Pillar 4: Experiments
- **What:** New styles, techniques, trends
- **Frequency:** 1 per week
- **Platform:** All
- **Format:** Varies
- **Caption:** "Trying something new" energy

## Batch Generation Schedule

**Sunday Prep Session (2-3 hours):**
1. Generate 5-7 hero images for the week
2. Create 2-3 process/thread visuals
3. Draft captions for all posts
4. Schedule or queue for manual posting

**Benefits:**
- Consistent quality (same session, same mindset)
- Time efficiency (setup once, generate many)
- Buffer for off-days
- Easier to maintain visual consistency

## Metrics to Track

| Metric | Why It Matters | Target (Month 1) |
|--------|----------------|------------------|
| Impressions | Reach | 10K+/week |
| Engagement Rate | Content quality | 3-5% |
| Follower Growth | Account health | 50-100/week |
| Replies/Comments | Community building | 5+/post |
| Retweets/Shares | Virality potential | 10+/post |

## Iteration Rules

1. **After 2 weeks:** Review top 3 posts, identify patterns
2. **After 1 month:** Double down on what works, drop what doesn't
3. **After 3 months:** Refine brand based on audience feedback
4. **Always:** A/B test posting times, formats, caption styles
