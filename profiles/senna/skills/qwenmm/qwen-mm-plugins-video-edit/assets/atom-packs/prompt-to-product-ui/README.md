# Prompt To Product UI Showcase

AI 产品 / SaaS 产品演示类视频资产包，沉淀自一段 prompt-to-UI 产品演示参考视频的拆解。

核心概念：用户输入一个 prompt，画面生成一个完整、有审美、有场景的产品 UI。

## 适合什么

- AI 产品能力展示
- SaaS 产品宣传
- Prompt-to-UI / Prompt-to-App 演示
- 数据分析平台、旅行规划、学习平台、移动 App 展示
- 需要“清爽、产品感、高完成度 UI、多风格生成”的宣传片

## 设计语言

- 暖白、米灰、浅砂色背景为主，和黑场霓虹科技感区分开。
- 白色圆角 prompt 输入框、黑色发送按钮、鼠标箭头贯穿全片。
- UI 结果以大圆角卡片、轻阴影、低边框、浮层拼贴展示。
- 每次风格变化都必须由输入、点击、滑块或选项触发。
- UI 不要像普通截图墙，要像“AI 正在生成不同产品原型”。

## 原子能力

1. `prompt-composer`：白色 prompt 输入框 + 黑色发送按钮 + 鼠标点击。
2. `ui-materialization`：点击后产品界面逐层生成。
3. `floating-product-collage`：多个 UI 模块组成有层级的产品拼贴。
4. `data-dashboard-bloom`：数据仪表盘、指标卡、图表逐层亮起。
5. `style-morph-slider`：滑块驱动界面换肤、字体和配色变化。
6. `retro-pixel-ui-mode`：蓝底像素风 UI，作为强记忆点。
7. `mobile-app-focus-reveal`：手机 App mockup 居中，适合结尾收束。

## 推荐结构

1. `0-4s`：极简品牌词或主词出现。
2. `4-10s`：Prompt Composer 输入任务。
3. `10-18s`：UI Materialization 生成第一个产品界面。
4. `18-28s`：Floating Product Collage 展示多个产品类型。
5. `28-36s`：Data Dashboard Bloom 或 Style Morph Slider 展示能力深度。
6. `36-43s`：Retro Pixel UI Mode 做强风格跳变。
7. `43-47s`：Mobile App Focus Reveal 或品牌关键词收束。
